This Project is a simple tictactoe game that, unfortunately, doesn't work due to some unresolved bugs. I did my best, though.
The project was done mostly with IntelliJ and the GUI was built with JavaFX. I cannot stress enough that this project was mostly done by myself, with assistance from ChatGPT trying to work through fixing bugs.

The Program was compiled and run by IntelliJ after pressing the "Run" button. To enusre all the JavaFX imports were available, the "lib" of the JavaFX download was added as a library to the Project and the appropriate "vmArgs" was also added.

Various OOP principles were used as directed by the given instructions. For example, a lot of variables were declared as private but were accessed using constructors later in the code, demonstrating encapsulation.
